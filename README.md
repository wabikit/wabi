# Wabi

> Beautifully imperfect components for Rails.

Wabi is an open-source UI component library for Ruby on Rails 8, built on Phlex + Tailwind + Stimulus.
Components are copied into your project — you own the code.

🚧 **Status:** alpha development (Sprint 0). Public release target: 2026-08.

## Monorepo layout

- `gem/` — the `wabi` Ruby gem (runtime + Rails generators)
- `registry/` — component source files and JSON build pipeline
- `docs/` — the `wabikit.dev` site (Rails + Phlex), also serves the registry

See `ROADMAP.md` for what's coming.
