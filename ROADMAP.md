# Wabi Roadmap

## v0.1 alpha (target: 2026-08)
20 components: Button, Input, Textarea, Label, Checkbox, Switch, Select, Card, Badge, Alert, Avatar, Separator, Dialog, Drawer, Tooltip, Popover, DropdownMenu, Toast, Tabs, Accordion. 8 themes + dark mode.

## v0.2 (target: 2026-10)
Combobox, Command, RadioGroup, Slider, Toggle, ToggleGroup, Sheet, NavigationMenu, ContextMenu, Pagination, Calendar, DatePicker. Theme builder UI.

## v0.3 (target: 2027-01)
DataTable, Form, Blocks (composed templates), community registry support.

## v1.0 (target: 2027-04)
API stability guarantee, external a11y audit, conference talks.
